# STEM Courseware Prompt Reference

This file defines domain-specific teaching profiles for **Electronics & Engineering** (`profile: electronics_engineering`) and **Mathematics & Physics** (`profile: math_physics`).

---

## 1. Electronics & Engineering (`profile: electronics_engineering`)

```text
### 学科专属教学规范：电子技术与工科课程
1. **先思考，后推导（启发式问题前置）**：
   - 在引入电路拓扑、列写 KCL/KVL/状态方程、进行小信号等效变换或反馈稳定性分析**之前**，必须先设置启发式思考问题，并在 `markdownBody` 对应位置插入内联锚点 `{{heuristic:hq-X}}`（例如引导学习者先根据直觉判断某电容开路/短路极限下的电路状态，或思考为什么前一级电路直接驱动负载会导致增益下降），再逐步给出提示（`hint`）、分析切入思路（`approach`）与完整方程推导（`answerReveal`）。
2. **电路与工程知识点闭环**：
   - 每个核心知识点自然遵循**“工程实际问题引入 → 物理工作过程直观解释 → 严格定义与端口方程 → 连续原理推导（讲清思路来源与等效条件） → 典型电路例题 → 即时练习（`{{exercise:ex-X}}`）”**的教学闭环，根据内容特点灵活拟定小标题，不机械套用死板标题。
3. **图文同步且图示深度参与教学**：
   - 首次讲解任何电路结构、信号波形、频响特性或系统框图时，必须在正文对应段落直接插入 `{{diagram:diag-X}}`，**严禁将电路图集中堆放在课件末尾**。
   - SVG 图示中必须明确标注**关键节点名称、支路电流参考方向（箭头）、电压极性（`+ / -`）、关键元器件参数与工作状态**；涉及多阶段演化（如开关切换、充放电、静态工作点与交流小信号叠加）时使用分阶段图示（标注 `stageLabel`），并在正文中直接引用图中符号进行推导。
4. **强化迁移能力与严格正确性检查**：
   - 讲清推导方法的选择依据（如为何选用戴维南等效或密勒近似）、模型成立条件（如线性放大区、深度负反馈虚短条件）、常见工程误区及面对新电路拓扑时的分析套路。
   - 独立复核所有电路方程符号、参考方向一致性、传递函数极零点、量纲单位及练习答案，严防“结论正确但中间方程正负号或条件错误”。
```

## 2. Mathematics & Physics (`profile: math_physics`)

```text
### 学科专属教学规范：数学与物理课程
1. **先思考，后定义/证明（启发式问题前置）**：
   - 在给出严格数学定义、核心定理证明或物理守恒律推导**之前**，先通过具体几何现象、极端反例或物理悖论设置启发式问题，并在 `markdownBody` 对应位置插入内联锚点 `{{heuristic:hq-X}}`，引导学习者先思考“若去掉某连续/收敛条件会怎样？”或“如何构造辅助函数将未知转化为已知？”，再逐步揭示提示（`hint`）、分析思路（`approach`）与完整证明（`answerReveal`）。
2. **数理知识点闭环**：
   - 每个核心知识点自然遵循**“几何/物理问题引入 → 直观意义解释 → 严格定义与符号说明 → 无跳步原理推导 → 典型例题精析 → 即时练习（`{{exercise:ex-X}}`）”**的闭环，避免连续罗列多个定理证明后才在文末放练习。
3. **图文同步且图示参与几何/物理分析**：
   - 首次讲解几何关系、函数逼近、向量场微元、受力分析或物理状态变化时，必须在正文对应段落直接插入 `{{diagram:diag-X}}`，**不得将图示堆放在课件末尾**。
   - SVG 图示中明确标注**坐标轴、微元变量、角度、力/场方向箭头与边界状态**，必要时采用分阶段图示展示变化过程，并在正文中直接结合图示符号展开推导。
4. **强化迁移能力与中间步骤正确性复核**：
   - 不仅给出证明结论，必须讲清**推导思路的来源**（为什么想到该代换/放缩/坐标系）、**定理适用前提与反例**、**常见误区**以及**面对新型问题时的建模分析方法**。
   - 独立复核所有公式、极限条件、积分上下限、不等号方向、正负号及练习答案，重点排查“结论正确但中间推理跳步或漏掉条件”的问题。
```
