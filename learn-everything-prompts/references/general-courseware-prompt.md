# General Academic & Computer Science Courseware Prompt Reference

This file defines domain-specific teaching profiles for **General Academic Subjects** (`profile: general_academic`) and **Computer Science** (`profile: computer_science`).

---

## 1. General Academic Subjects (`profile: general_academic`)

```text
### 学科专属教学规范：通用专业课程
1. **先思考，后讲解**：
   - 在引入核心概念、理论模型、机制推导或案例分析**之前**，先设置启发式思考问题，并在 `markdownBody` 对应位置插入内联锚点 `{{heuristic:hq-X}}`，引导学习者先根据已有常识或前置知识独立思考，再逐步揭示提示（`hint`）、分析切入点（`approach`）与完整解释（`answerReveal`）。不要将全部思考题集中在课件末尾。
2. **灵活应用知识点闭环（不机械套用固定标题）**：
   - 每个核心知识点遵循**“实际问题引入 → 直观解释 → 严格定义 → 原理推导/机制论证 → 典型例题/案例 → 即时练习（`{{exercise:ex-X}}`）”**的内在教学顺序，根据学科特点灵活设计自然的小标题，避免连续讲解大量理论后才安排练习。
3. **图文同步与图示参与教学**：
   - 首次讲解结构关系、因果回路、状态演化或分类对比框架时，直接在正文对应位置插入 `{{diagram:diag-X}}`，图中明确标注关键变量、作用方向与状态变化，不得将图示集中堆放在文末。
4. **强化迁移能力与严格自检**：
   - 讲清理论推导思路的来源、适用前提条件、常见误区及面对新情境时的分析方法；独立复核所有逻辑链条、公式符号与练习题答案，表达简洁规范。
```

## 2. Computer Science (`profile: computer_science`)

```text
### 学科专属教学规范：计算机科学与算法工程
1. **先思考，后设计（启发式引导前置）**：
   - 在给出高效算法、数据结构不变式或系统架构方案**之前**，先针对朴素方法的性能瓶颈或并发/边界冲突提出启发式问题，并在 `markdownBody` 对应位置插入内联锚点 `{{heuristic:hq-X}}`，引导学习者先思考优化方向，再逐步展开提示（`hint`）、核心思路（`approach`）与完整设计（`answerReveal`）。
2. **知识点闭环与状态图文同步**：
   - 每个核心算法或系统机制遵循**“实际工程/计算瓶颈引入 → 直观状态图解 → 严格定义与不变式 → 原理与复杂度推导 → 典型例题（含逐步执行追踪） → 即时练习（`{{exercise:ex-X}}`）”**的闭环。
   - 首次讲解指针移动、树图遍历、DP 状态转移、内存布局或协议状态机时，必须在正文对应位置插入 `{{diagram:diag-X}}`，在 SVG 图中明确标注索引变量、转移方向箭头与阶段状态，严禁把图示堆放在文末。
3. **强化迁移能力与边界正确性复核**：
   - 讲清算法思路的来源（如何从暴力解观察出单调性/重叠子问题）、适用前提、常见边界误区（如 `off-by-one`、空集、溢出）及面对变种问题时的分析方法；独立复核代码逻辑、复杂度推导与练习答案。
```
